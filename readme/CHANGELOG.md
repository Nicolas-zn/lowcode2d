# 更新日志

## [2026-03-26] GIS 交互系统完善

### ✨ 新增功能

1. **动作参数系统**
   - 所有动作支持自定义参数
   - 参数通过 `actionParams` 配置

2. **新增内置动作**
   - `flyTo`: 飞行到对象（支持时长和距离参数）
   - `changeColor`: 改变对象颜色（支持颜色和透明度）
   - `showInfo`: 显示对象信息（支持标题和时长）

3. **配置面板增强**
   - 动作参数配置对话框
   - 事件测试功能
   - 实时参数调整

### 🔧 改进

1. **ActionEngine**
   - 支持动作配置对象 `{ name, params }`
   - 向后兼容字符串格式

2. **EventConfigPanel**
   - 新增参数配置按钮
   - 新增测试按钮
   - 改进 UI 布局

3. **CesiumBrick**
   - 自动转换事件配置格式
   - 支持动作参数传递
